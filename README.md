# CodeAlpha_Iris-Flower-Classification
Iris Flower Classification is a CodeAlpha machine learning project that classifies iris flowers into different species based on features such as sepal length, sepal width, petal length, and petal width. The project uses machine learning algorithms to train a model and accurately predict the species of an iris flower from its given features. 
# Iris Flower Classification

## Project Description
This project is part of the CodSoft Data Science Internship (Task 3).

The objective is to classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica
